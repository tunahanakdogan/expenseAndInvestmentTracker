# CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Her PR'da ve `main` push'unda backend ve frontend testlerini çalıştıran GitHub Actions workflow'u.

**Architecture:** Tek dosya `.github/workflows/ci.yml`, iki paralel job (`backend`, `frontend`), path filtresi yok.

**Tech Stack:** GitHub Actions — `actions/checkout@v7`, `actions/setup-java@v6` (temurin 25, maven cache), `actions/setup-node@v7` (Node 26, npm cache).

**Spec:** `docs/superpowers/specs/2026-11-15-ci-design.md`

## Global Constraints
- Job adları tam olarak `backend` ve `frontend` (ruleset'te bu adlar seçilecek).
- `permissions: contents: read`; secret kullanılmaz.
- Tetikleyici: `pull_request` + `push` (`branches: [main]`); `concurrency` grubu `ci-${{ github.ref }}`, `cancel-in-progress: true`.

## Review Focus
- `backend/mvnw` git'te 100644 kayıtlı (Windows'tan commit) → Linux'ta "Permission denied". Exec bit eklenmeli (Task 1, Step 1).
- `package-lock.json` Windows'ta üretildi → Linux native paketleri (`@rolldown/binding-linux-x64-gnu`, `@esbuild/linux-x64`, `lightningcss-linux-x64-gnu`, `sass-embedded-linux-x64` …) lockfile'da olmalı. Kontrol edildi: mevcut.
- Runner locale'i `en_US` → Türkçe locale hatası CI'da görünmez; lokal Windows'ta `pom.xml` surefire argLine ile korunuyor (değişiklik yok).
- Testcontainers Oracle imajı (`gvenzl/oracle-free:23-slim`) her çalışmada indirilir; süre ~2-4 dk kabul.
- Frontend `npm test` watch modunda takılmasın: `-- --watch=false` zorunlu.

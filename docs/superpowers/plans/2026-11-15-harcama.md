### Task 3: Dönem kuralı ve taksit bölme (`PaymentPlan`)

**Files:**
- Create: `backend/src/main/java/com/tunahan/finans/expense/PaymentPlan.java`
- Test: `backend/src/test/java/com/tunahan/finans/expense/PaymentPlanTest.java` (saf birim testi, Spring yok)

**Interfaces:**
- Produces (`final class PaymentPlan`, paket-özel, durumsuz):
  - `static YearMonth firstPeriod(LocalDate expenseDate, Integer statementDay)` — `statementDay == null` (nakit/banka) → harcama ayı. Kart: etkin kesim günü = `min(statementDay, ayın son günü)`; `gün ≤ etkin` → harcama ayı, değilse sonraki ay.
  - `static List<YearMonth> periods(LocalDate expenseDate, Integer statementDay, int count)` — taksit `i` → `firstPeriod + (i−1)` ay.
  - `static List<BigDecimal> split(BigDecimal total, int count)` — `part = total.divide(count, 2, HALF_EVEN)`; ilk `count−1` eleman `part`, son = `total − part × (count−1)`. Herhangi bir eleman ≤ 0 ise `BusinessRuleException("Tutar bu taksit sayısına bölünemeyecek kadar küçük")`.

- [ ] **Step 1: Başarısız testleri yaz:**

```java
// firstPeriod — kesim günü 15
assertThat(firstPeriod(LocalDate.of(2026, 11, 10), 15)).isEqualTo(YearMonth.of(2026, 11)); // öncesi
assertThat(firstPeriod(LocalDate.of(2026, 11, 15), 15)).isEqualTo(YearMonth.of(2026, 11)); // aynı gün
assertThat(firstPeriod(LocalDate.of(2026, 11, 16), 15)).isEqualTo(YearMonth.of(2026, 12)); // sonrası
// kesim günü 31, kısa aylar
assertThat(firstPeriod(LocalDate.of(2027, 2, 28), 31)).isEqualTo(YearMonth.of(2027, 2));   // etkin 28
assertThat(firstPeriod(LocalDate.of(2026, 11, 30), 31)).isEqualTo(YearMonth.of(2026, 11)); // etkin 30
assertThat(firstPeriod(LocalDate.of(2028, 2, 29), 28)).isEqualTo(YearMonth.of(2028, 3));   // artık yıl, 29 > 28
// yıl geçişi
assertThat(firstPeriod(LocalDate.of(2026, 12, 20), 15)).isEqualTo(YearMonth.of(2027, 1));
assertThat(periods(LocalDate.of(2026, 11, 10), 15, 3))
        .containsExactly(YearMonth.of(2026, 11), YearMonth.of(2026, 12), YearMonth.of(2027, 1));
// nakit/banka
assertThat(firstPeriod(LocalDate.of(2026, 11, 30), null)).isEqualTo(YearMonth.of(2026, 11));

// split
assertThat(split(new BigDecimal("100"), 3)).containsExactly(new BigDecimal("33.33"), new BigDecimal("33.33"), new BigDecimal("33.34"));
assertThat(split(new BigDecimal("0.05"), 2)).containsExactly(new BigDecimal("0.02"), new BigDecimal("0.03"));
assertThat(split(new BigDecimal("250.50"), 1)).containsExactly(new BigDecimal("250.50"));
assertThatThrownBy(() -> split(new BigDecimal("0.26"), 36)).isInstanceOf(BusinessRuleException.class); // son taksit eksi
assertThatThrownBy(() -> split(new BigDecimal("0.01"), 2)).isInstanceOf(BusinessRuleException.class);  // ilk taksit 0
```
(`containsExactly` yerine `compareTo` tabanlı karşılaştırma gerekirse `usingComparatorForType(BigDecimal::compareTo, BigDecimal.class)`.)

Property testi `splitAlwaysSumsToTotal` — `new Random(20261115)`, 10 000 tur: `total` = 1..100 000 000 kuruş (`BigDecimal.valueOf(kuruş, 2)`), `count` = 1..36. Ya `BusinessRuleException` fırlar ya da: boyut `count`; toplam `compareTo(total) == 0`; her eleman > 0 ve scale ≤ 2; ilk `count−1` eleman birbirine eşit ve `total.divide(count, 2, HALF_EVEN)`'e eşit. Ek: `total ≥ 1.00` olan turlarda istisna **fırlamaz**.

## Spec'te açık kalıp bu planda karara bağlananlar

| Konu | Karar |
|---|---|
| Hesap/kategori "harcaması var mı" kontrolü (bağımlılık yönü `expense → account`) | Kendi repository'sinde `expense` tablosuna native sayım; account/category, expense paketine referans vermez |
| Aynı adla hesap/kategori | 422, Türkçe mesaj; adlar `strip()` edilir |
| Silme reddi mesajları | "Harcaması olan hesap silinemez" / "Harcaması olan kategori silinemez" |
| Kart olmayan hesapta `statementDay` gönderilirse | Yok sayılır (`null`) ; kartta eksikse 422 |
| İstek tutarının hassasiyeti | En çok 2 ondalık (400); yanıtlar scale 4 |
| Taksitin 0 veya eksi çıkması | 422 "Tutar bu taksit sayısına bölünemeyecek kadar küçük" |
| Aylık liste yanıt biçimi | `{ period, payments[], totals[] }`; eşit tarihte `id` azalan; `totals` para birimi koduna göre sıralı |
| HTTP kodları | POST 201, DELETE 204 |
| Tüm kategoriler silinirse | Sonraki `GET` varsayılanları yeniden oluşturur (spec'in "hiç kategorisi yoksa" ifadesi birebir uygulanır) |
| Hızlı giriş / detay sunumu | `MatBottomSheet` / `MatDialog`; yeni route yok; tarih için native `type="date"` (datepicker adaptörü `app.config.ts`'e dokunmayı gerektirirdi) |
| `AccountApi`, `CategoryApi` konumu | `settings/` (yönetildikleri yer); `expenses/` oradan içe aktarır; `shared/`'e dosya eklenmez |

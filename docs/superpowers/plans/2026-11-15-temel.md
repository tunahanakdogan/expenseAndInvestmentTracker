# Temel (Parça 0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Üç paralel parçanın üzerine kurulacağı ortak tipler, fiyat okuma katmanı, sözleşmeler ve uygulama kabuğu.

**Architecture:** Backend'de `common` (Money, AssetType, CurrentUser, istisnalar, JSON config) ve `pricing` (V2 tabloları, entity/repository, `PriceQueryService`, `/api/pricing/rate`, `TrackedAssetSource`). Frontend'de `shared` (money pipe, parseAmount) ve `shell` (alt/yan menü) + üç yer tutucu lazy route.

**Tech Stack:** Spring Boot 4.1 (Jackson 3), Oracle + Flyway, Angular 22 + Material, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-15-ilk-tur-design.md` (Parça 0)

## Global Constraints
- Para `BigDecimal`, `RoundingMode.HALF_EVEN`; tutar `NUMBER(19,4)`, birim fiyat/kur `NUMBER(19,8)`, adet `NUMBER(19,8)`.
- JSON'da `BigDecimal` string, `toPlainString`.
- Arayüz metinleri Türkçe; kod İngilizce.
- Yeni kütüphane yok.

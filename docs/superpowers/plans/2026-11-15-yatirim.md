**Interfaces:**

- Produces:
  - `enum TransactionType { BUY, SELL }`
  - `final class PositionCalculator` (Spring bean değil, durumsuz):
    - `static final int SCALE = 8;`
    - `record Trade(TransactionType type, BigDecimal quantity, BigDecimal unitPrice, BigDecimal commission, BigDecimal fxRateTry)` — `fxRateTry` yalnız `trackTry` iken okunur.
    - `record Position(BigDecimal quantity, BigDecimal costBasis, BigDecimal averageCost, BigDecimal realizedGain, BigDecimal costBasisTry, BigDecimal averageCostTry, BigDecimal realizedGainTry)` — `trackTry == false` ise son üç alan `null`.
    - `static Position calculate(List<Trade> trades, boolean trackTry)` — `trades` çağıran tarafından `tradeDate`, sonra `id` sırasına dizilmiş gelir. Fazla satışta `BusinessRuleException("Eldeki adetten fazla satılamaz")`.

Algoritma (spec; her atama `setScale(8, HALF_EVEN)`; ortalama **durumdur**, yalnız BUY'da yeniden hesaplanır):

```
başlangıç: qty = cost = avg = realized = 0  (trackTry ise costTry = avgTry = realizedTry = 0)
BUY : qty += q; cost += q×p + c; avg = cost / qty
      costTry += (q×p + c) × fx; avgTry = costTry / qty
SELL: q > qty → BusinessRuleException
      realized    += q×p − c − avg×q
      realizedTry += (q×p − c) × fx − avgTry×q
      qty −= q
      qty == 0 → cost = costTry = avg = avgTry = 0
      değilse  → cost = avg × qty; costTry = avgTry × qty   (avg, avgTry değişmez)
```
